# Small-Tools

> A collection of useful and simple developing tools in one place.

## 📌 About

**Small-Tools** is a personal project that brings together small, practical tools in a simple and easy-to-use interface.

The project is designed to keep useful utilities accessible from a single front page.

## 🛠️ Tools

### 📷 Photo Editor
A tool for editing and working with images.

### 🔳 QR Code Generator
Generate QR codes from text, links, or other supported information.

### 🔐 Password Generator
Generate strong and random passwords for better account security.

### ❤️ FLAMES
A fun FLAMES relationship calculator based on two names.

## 🖥️ Interface

The Small-Tools front page provides:

- Simple and clean design
- Large tool buttons
- Mobile-friendly layout
- Easy navigation
- Lightweight interface
